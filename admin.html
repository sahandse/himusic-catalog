🔑 اتصال به گیت‌هاب

یک توکن با دسترسی repo بساز: GitHub → Settings → Developer settings → Personal access tokens → Generate new token (classic), اسکوپ repo را تیک بزن. توکن فقط در حافظه همین مرورگر (localStorage) ذخیره می‌شود و به جای دیگری ارسال نمی‌شود؛ آن را در اختیار کسی قرار نده.

➕ افزودن موزیک ویدیو جدید

برای پیدا کردن لینک مستقیم ویدیو: صفحه ویدیو را باز کن، کلید F12 را بزن (تب Network)، روی ویدیو پخش بزن و فایل mp4 را در لیست درخواست‌ها پیدا کن، سپس روی آن راست‌کلیک و Copy → Copy link address را بزن.
